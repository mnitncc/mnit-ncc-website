# 🎖️ NCC Chapter Website

A modern frontend web application designed for the National Cadet Corps (NCC) chapter. The website provides a comprehensive digital presence with dynamic animations, responsive design, and smooth interactions.

## ✨ Features

- **Modern Design**: Clean and professional aesthetic fitting for the NCC organization.
- **Smooth Animations**: Engaging entrance and scroll animations powered by Framer Motion.
- **Responsive Layout**: Fully accessible across all device sizes (mobile, tablet, desktop).
- **Iconography**: Integrated with Lucide React for consistent and crisp vector icons.
- **Fast Performance**: Built with Vite for rapid development and lightning-fast loading speeds.

## 🛠️ Tech Stack

- **Frontend Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 🚀 Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/himansh24dev/ncc-mnit-website.git
   cd ncc-mnit-website
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Start the development server
   ```bash
   npm run dev
   ```

4. Open `http://localhost:5173` to view it in your browser.
